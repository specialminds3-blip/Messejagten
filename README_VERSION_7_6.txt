Messejagten version 7.6

Upload index.html, app.js og style.css til roden af GitHub-repository og erstat de eksisterende filer.
Ingen ny SQL nødvendig; version 7.5 skal være installeret i Supabase.

Ny afslutningsskærm med point, foreløbig placering og knap til hele ranglisten.
Holdnavnsfeltet viser nu "Holdnavn + SUF afdeling".

Bemærk: Den eksisterende ranglistefunktion returnerer ikke hold-id. Hvis flere hold har nøjagtigt samme navn, vises ingen individuel placering på afslutningsskærmen for at undgå forveksling; hele ranglisten kan stadig ses.

Test anbefales efter GitHub Pages-udgivelsen.
