MESSEJAGTEN 7.8

1. Kør SUPABASE_VERSION_7_8.sql i Supabase SQL Editor (kun én gang). Det opretter automatisk opgaven Gruppebillede ved fremtidige arrangementer. Eksisterende arrangementer ændres ikke.
2. Upload/erstat på GitHub: index.html, app.js, slideshow.html, slideshow.js, slideshow.css. De øvrige filer fra 7.7 skal blive liggende.
3. Kontrollér GitHub Actions er grøn.

Nyt: ventetekst skjules når billeder findes, holdnavn vises i mørk bjælke på Gruppebillede i slideshow, fotooplysning, automatisk oversigt når alle opgaver er besvaret. Gemte svar kan stadig rettes før aflevering.

Bemærk: Automatisk opgave oprettes kun for NYE arrangementer. Test gerne ved at oprette et kladdearrangement.
