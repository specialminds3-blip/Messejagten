Messejagten 7.4 – offentliggørelse af resultater

1. Kør hele SUPABASE_VERSION_7_4.sql i Supabase SQL Editor.
2. Upload alle webfiler fra Messejagten-main til GitHub-roden (SQL-filen behøver ikke uploades).
3. Opdater admin.html og vælg arrangement. Offentliggør først efter bedømmelse.
4. Afleveret hold kan trykke Se resultater.
5. Administrator kan trække offentliggørelse tilbage.

Bemærk: Pointene beregnes live fra bedømmelser; rettelser efter offentliggørelse slår igennem. Test med et testarrangement inden brug.
